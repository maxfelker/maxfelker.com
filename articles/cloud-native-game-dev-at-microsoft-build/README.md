At Microsoft Build 2024, I presented **BRK254 — Supercharging game dev with Microsoft's cloud native and AI technology**. 

This hour-lon live talk and demo explores how teams can integrate cloud-native concepts such as containers, cloud storage, and hosted databases  directly into game development workflows. We explore the production-first mindset, ingreating cloud-native backend services from day one, deploy WebGL games from Unity3D into Azure, and using AI to accelerate the dev loop.
