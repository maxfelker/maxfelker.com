At Microsoft Build 2024 I presented **BRK254 — Supercharging game dev with Microsoft's cloud native and AI technology**. The talk shows how cloud-native building blocks such as containers, cloud storage, and hosted databases can integrate directly into a Unity game development workflow. We explore the production-first mindset, ingreating cloud-native backend servicesfrom day one, leaning on managed infrastructure instead of hand-rolled ops, and using AI to accelerate both how the game gets built and how it plays.ss
