At Microsoft Build 2024 I presented **BRK254 — Supercharging game dev with Microsoft's cloud native and AI technology**. The session above is the main event; here's the short version.

Game studios feel the same pressure as every other software team: ship faster, scale on demand, and fold AI into the experience without drowning in infrastructure. The talk shows how cloud-native building blocks — containers, managed services, and elastic compute — paired with Microsoft's AI tooling let a small team move at a pace that used to require a whole platform org.

I walk through the patterns that matter: treating backend services as cloud-native from day one, leaning on managed infrastructure instead of hand-rolled ops, and using AI to accelerate both how the game gets built and how it plays.

If you lead a team trying to take a game from prototype to production, this is the playbook I'd start from.
